# v0.5.91

## Overview

Knowledge loading recovers the resident daemon before starting local fallback work and avoids recursive source enumeration when a complete, alias-free persisted snapshot can be validated through its recorded paths. Large source scans yield between batches so daemon lifecycle requests can make progress.

**Full Changelog**: https://github.com/catlog22/maestro-flow/compare/v0.5.90...v0.5.91

## Highlights

- Start daemon recovery before typed and untyped local load fallback; a caller timeout no longer prevents the recovery attempt from starting.
- Reuse recorded source paths for complete, alias-free cache snapshots, preserving file, directory, optional-source, and publication freshness checks.
- Keep full source resolution for legacy snapshots and snapshots with aliases, including chained links. Only publishers migrate obsolete snapshot metadata; readers remain zero-write.
- Yield after each 64 scanned paths to reduce event-loop starvation during large history scans.
