# v0.5.85

## Overview

Hardens the daemon-backed knowledge search into a governed, observable and
single-writer surface: a ripgrep-backed fixed-string `--exact` route that never
enters ranking, request-scoped `--diagnostics` with a stable schema, and
boundary-computed candidate budgets shared by CLI and Dashboard. Wiki cache
publication becomes single-writer through a file-based publisher lease with
explicit reader/publisher/hermetic indexer roles, while freshness and
throughput experiments (incremental source-manifest indexing, structured
embedding fragments, a v9 compiled-postings cache) ship opt-in and fail closed
without changing the default result contract. The impeccable workflow is
restructured from flat phase files into a self-contained, distributable
Impeccable 4.1.3 skill bundle with four dedicated role agents, and the
workflow/template/agent-mirror documentation aligns architecture templates as
reference-only global evidence.

**Full Changelog**: https://github.com/catlog22/maestro-flow/compare/v0.5.84...v0.5.85

## Highlights

- **Governed exact search and observable requests**: `maestro search --exact` runs through the bundled `@vscode/ripgrep` and returns deterministic filePath/line/column/preview results without ranking or fusion; opt-in `--diagnostics` emits bounded, request-scoped attribution (phases, fallback reasons, provider/cache/embedding state) so a result can be traced to daemon, indexer or fallback without changing the default contract.
- **Single-writer wiki publication**: the daemon holds a file-based publisher lease (`wiki-index-publisher.lock`, acquire/release/reclaim) while Dashboard routes act read-only unless no daemon owner exists — indexer roles (reader/publisher/hermetic) replace the old persistence flags.
- **Fail-closed freshness and throughput experiments**: an opt-in incremental index keyed by a content-addressed source manifest, structured embedding fragments that collapse back to their parent entry, a 4-minute transcript reconciliation timer, and an opt-in v9 compiled-postings cache that stays read-compatible with v7/v8 — all off by default and gated by env flags.
- **Self-contained Impeccable skill**: `workflows/impeccable/` is now a vendored, distributable core (SKILL.md 4.1.3 + reference/ + live/detector/hook scripts, LICENSE/NOTICE/UPSTREAM provenance) resolved exclusively from Maestro-owned paths, with asset-producer, documenter, finish-reviewer and manual-edit-applier role agents — flat phase files are retired and external impeccable resolution/install/update is forbidden.

## Features

- `d18b0422` feat(release): freeze v0.5.85 workspace WIP (search/wiki, impeccable, docs alignment).
  - Ripgrep-backed governed exact search (`src/search/exact-search.ts`): literal option-looking queries stay literal, caps fail closed, truncation is marked, linked repositories require an explicit codebase share; new dependency `@vscode/ripgrep`.
  - Request-scoped search diagnostics (`src/search/diagnostics.ts`): schema `maestro-search-diagnostics/1.0`, bounded 16 KiB / 32 phases / 16 fallbacks with sanitized fields; older daemons without diagnostics remain compat-success.
  - Candidate budget computed once at the request boundary and shared by CLI and Dashboard; adaptive mode opt-in via `MAESTRO_SEARCH_ADAPTIVE_BUDGET=1` (hard cap 500, single escalation).
  - Structured embedding fragments (`dashboard/src/server/wiki/structured-fragments.ts`): markdown/text/code chunks keep heading hierarchy, split long sections with overlap and deterministic hashes, and collapse vector hits back to the parent WikiEntry so fragments never surface as public results; artifacts carry a policy-checksum fence and never mix with legacy chunks.
  - Arch-KB template loading without the daemon: `maestro load` gains type `template` backed by the arch-kb index, plus a new spec-wiki loader over bounded file scopes.

## Compatibility Notes

- New runtime dependency: `@vscode/ripgrep` (optional platform binaries) backs `maestro search --exact`.
- `--exact` and `--diagnostics` are new opt-in search flags; the default search contract is unchanged.
- Default-off experiments: `MAESTRO_SEARCH_ADAPTIVE_BUDGET=1`, `MAESTRO_SEARCH_COMPILED_POSTINGS=1`, incremental indexing and structured chunks must be enabled explicitly and fail closed.
- Wiki cache publication is single-writer: with a resident daemon, Dashboard serves read-only; without one, Dashboard publishes through a short atomic lease.
- Impeccable is fully embedded: `workflows/impeccable/` ships the 4.1.3 core (Apache-2.0, see NOTICE/UPSTREAM) and `maestro-impeccable` no longer resolves, installs or updates an external impeccable Skill.
